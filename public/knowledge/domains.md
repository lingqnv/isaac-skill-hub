# Isaac Skill Hub — Domain Taxonomy

Skills are organized into 8 primary domains. Each skill belongs to one primary domain and up to 3 secondary tags.

## Domains

### Navigation
Movement, mapping, and localization. Path planning, SLAM, obstacle avoidance, multi-robot coordination, fleet management.

**Example skills:** nav-slam-lidar, multi-robot-coord

### Manipulation
Object interaction. Grasp planning, motion planning, force control, assembly, bin picking.

**Example skills:** grasp-6dof-transformer

### Perception
Understanding the world. Object detection, pose estimation, scene understanding, depth processing, semantic segmentation.

**Example skills:** perception-yolo-ros2, pose-estimation-foundationpose

### Data & Training
Data generation and ML pipelines. Domain randomization, synthetic data annotation, curriculum learning, dataset curation.

**Example skills:** domain-rand-factory, synthetic-data-annotator

### Simulation
Virtual environments. Scene generation, physics tuning, sensor simulation, digital twins, environment procedural generation.

**Example skills:** isaac-sim-warehouse

### Control
Low-level control. PID tuning, reinforcement learning policies, model predictive control, adaptive control, locomotion.

**Example skills:** pid-auto-tuner, rl-locomotion-anymal

### Safety
Safety-critical systems. Collision detection, workspace monitoring, emergency stop, ISO compliance, zone enforcement.

**Example skills:** safety-zone-monitor

### Integration
Connecting systems. ROS bridges, cloud deployment, edge optimization, hardware drivers, fleet management backends.

**Example skills:** ros2-cloud-bridge
