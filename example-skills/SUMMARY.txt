1. GRASP-6DOF-TRANSFORMER
   File: grasp-6dof-transformer/SKILL.md
   Lines: 161 | License: Apache 2.0
   Domain: Manipulation
   Execution: Hybrid (GPU inference + CPU planning)
   
   Inputs:
   - sensor_msgs/PointCloud2 (required)
   - sensor_msgs/Image (optional RGB for visual context)
   
   Outputs:
   - geometry_msgs/PoseArray (grasp poses with confidence)
   - trajectory_msgs/JointTrajectory (executable grasp trajectory)
   
   Key Parameters:
   - num_grasps: 1-50 (default 5)
   - confidence_threshold: 0.0-1.0 (default 0.6)
   - gripper_width_mm: 50-200 (default 100)
   - planning_time_ms: 50-1000 (default 200)
   
   Workflows:
   - High-precision bin picking (num_grasps=10, threshold=0.75)
   - Fast assembly-line picking (num_grasps=3, threshold=0.55)
   - Large object handling (gripper_width_mm=150)
   
   Specs: 150-300ms latency, 3-5 plans/sec, 2.5GB GPU memory

2. PERCEPTION-YOLO-ROS2
   File: perception-yolo-ros2/SKILL.md
   Lines: 170 | License: Apache 2.0
   Domain: Perception
   Execution: Hybrid (GPU inference + CPU post-processing)
   
   Inputs:
   - sensor_msgs/Image (RGB 8UC3)
   - sensor_msgs/CameraInfo (camera calibration)
   
   Outputs:
   - vision_msgs/Detection2DArray (detected objects)
   - sensor_msgs/Image (annotated output with boxes)
   - geometry_msgs/PoseArray (3D object poses)
   
   Key Parameters:
   - model_variant: yolov8n|s|m|l or yolov9c|m (default yolov8m)
   - confidence_threshold: 0.0-1.0 (default 0.5)
   - input_size: 320/416/512/640/832/1024 (default 640)
   - inference_device: cuda|cpu|tensorrt (default cuda)
   - max_detections: 1-500 (default 100)
   
   Workflows:
   - Warehouse inventory (model=yolov8n, input=416, threshold=0.4)
   - Precision inspection (model=yolov9m, input=832, threshold=0.75)
   - Mobile robot real-time (model=yolov8s, input=640, threshold=0.55)
   
   Specs: 30-100ms latency, 10-30 FPS, 1-4GB GPU memory

3. SAFETY-ZONE-MONITOR
   File: safety-zone-monitor/SKILL.md
   Lines: 180 | License: Apache 2.0
   Domain: Safety
   Execution: Real-world only (NOT simulation)
   
   Inputs:
   - nav_msgs/OccupancyGrid (from costmap or custom)
   - geometry_msgs/PoseStamped (robot pose)
   - sensor_msgs/PointCloud2 (lidar/depth for immediate detection)
   
   Outputs:
   - std_msgs/Bool (safety_status: true=safe, false=violation)
   - geometry_msgs/TwistStamped (distance to nearest obstacle)
   - std_msgs/Bool (emergency_stop trigger)
   
   Key Parameters:
   - nominal_zone_radius_m: 0.5-10.0 (default 2.0, ISO 13482)
   - warning_zone_radius_m: 0.2-5.0 (default 1.0, reduced speed zone)
   - emergency_zone_radius_m: 0.1-2.0 (default 0.3, immediate e-stop)
   - monitoring_frequency_hz: 10-200 (default 100, safety critical)
   - enable_human_presence_detection: true/false (default true)
   - dwell_time_ms: 0-500 (default 100, human reaction time)
   
   Workflows:
   - Industrial cobot (ISO 13482, nominal=2m, warning=1m, emergency=0.3m)
   - Research lab no-human (nominal=3.5m, warning=2m, enable_detection=false)
   - Mobile manipulation (nominal=1.5m, warning=0.8m)
   
   Specs: 100+ Hz monitoring, <100ms e-stop latency, ISO 13482 certified

4. DOMAIN-RAND-FACTORY
   File: domain-rand-factory/SKILL.md
   Lines: 193 | License: Apache 2.0
   Domain: Data & Training
   Execution: Sim-only (Isaac Sim GPU rendering)
   
   Inputs:
   - file: USD/USDZ scene (physics-enabled with camera rigs)
   - file: YAML randomization config (ranges for materials/lighting/poses)
   
   Outputs:
   - directory: randomized_scenes (N USD snapshots)
   - directory: rgb_images (PNG format, 1920x1080 default)
   - directory: depth_maps (16UC1 normalized depth)
   - file: annotation_data (JSON with bboxes, masks, 6D poses)
   
   Key Parameters:
   - num_samples: 100-1000000 (default 10000)
   - render_resolution: 640x480|1280x720|1920x1080|2560x1440 (default 1920x1080)
   - randomize_materials: true/false (default true)
   - randomize_lighting: true/false (default true)
   - randomize_poses: true/false (default true)
   - randomize_camera: true/false (default false)
   - batch_size: 1-500 (default 100, speed vs memory trade-off)
   - max_worker_threads: 1-16 (default 4, CPU cores/2 recommended)
   - enable_semantic_segmentation: true/false (default true)
   
   Workflows:
   - Grasping network (50k samples, all randomizations, batch=128)
   - Pose estimation fine-tune (10k samples, only pose random, batch=200)
   - Industrial part detection (100k samples, high res, batch=32)
   
   Specs: 50-200 images/sec, typical dataset 10k-100k, requires 100+GB disk for 1M
